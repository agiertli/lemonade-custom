Lessons Learned

#Lesson
1L40S vs L4 matters. Adding a 3rd TranslateGemma on L4 instead of L40S degraded throughput by 40%. Slower GPU creates a "slow lane."
2KServe headless services break load balancing. LLaMA had 2 replicas but only 1 got traffic. ClusterIP service fixed it instantly.
3Match CPU limits to worker count. 8 workers + 4 CPU = 0.5 CPU per worker = saturation under load.
4Benchmark iteratively. The "optimized" L4 config was 2x worse. Without re-benchmarking, we wouldn't have caught it.
